## 2026-11-14 初版

2026-11-14，macOS，Python 3.14.7。

执行 `python3 -m unittest discover -s tests -v`：9 项通过。覆盖生成器配对与可解性、手算增量、完整二轮依赖、持久化决策一致性、虚假证据拒绝、中途请求失败保留部分轨迹、CLI 与导出、HTTP 协议和预算错误。

HTTP 测试仅绑定 127.0.0.1 临时端口，用可控响应替换模型服务；测试进程对回环地址绕过系统代理。首次执行受环境端口权限限制，获准本机测试后执行；代理干扰经隔离后通过。没有请求外部模型服务。

执行离线命令生成 `examples/offline-demo`：2 轮、12 条回合、36 条环境转移。第一轮 bridge 四条轨迹均出现掉分后立即撤销，下一轮 Challenger 引用这些轨迹并再次生成 bridge 目标题；第二轮仍观察到该行为。这只是确定性替身的循环演示，不是训练收益。

独立审查发现 API 中途失败丢失当前回合部分轨迹，已修复并增加回归测试。逐行检查所有源文件与测试的非空 Python 行均有注释。SVG 通过 XML 解析并渲染检查。

未验证：所选真实模型及服务商兼容性、真实 API 生成有效 JSON 的成功率、模型行为差异、GPU 与梯度训练、泛化或学习收益。当前没有实现 PPO/GAE 或 Challenger 参数更新。
